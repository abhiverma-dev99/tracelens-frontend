Quickstart

Get TraceLens up and running in a few minutes. Connect your repository and instrument your application to start capturing live runtime crashes and deployments.

1 Connect GitHub Webhook

This allows TraceLens to track your recent pushes. Go to your repository Settings > Webhooks > Add webhook.

  • Payload URL: https://tracelens-7hdm.onrender.com/api/webhooks/github/<YOUR_API_KEY>
  • Content type: Select application/json
  • Select Just the push event and save.

2 Node.js Integration

Drop this snippet into your index.js or global error handler to capture Node.js crashes.

javascript

            nodeCode
          }}

3 Python Integration

For Python workers or scripts, wrap your execution block with this error reporter.

python

How to Test (End-to-End)

Follow these exact steps to see TraceLens in action:

Step 1: Write a Bug

Create a file named test.js. Paste the Node.js Integration snippet above, and add a fake crash at the bottom of the file:

// Deliberate crash for testing
setTimeout(() => {{ '{' }}
  throw new Error("Testing TraceLens Connection!");
{{ '}' }}, 1000);

Step 2: Push to GitHub

Commit this buggy code and push it to your repository. This triggers the Webhook.

git add test.js
git commit -m "Added test bug"
git push origin main

Step 3: Run the Code Locally

Execute the file in your terminal. It will crash and trigger the API.

node test.js

Check Your Dashboard!

Go to TraceLens. The incident and the exact commit will be correlated automatically.

Securing Your Ingest Key

Do not expose your key in public repositories.

Instead of hardcoding the Bearer token in the snippets above, store it in an Environment Variable (e.g., a .env file) that is ignored by Git.
