What is TraceLens?

TraceLens is an AI-powered incident and debugging platform for developers. When your Node app throws, TraceLens stores the error, stack trace, and service name. You can then open the incident, see recent deployments, and ask AI for a likely root cause and a suggested fix.

Quick Start

  1. Create a TraceLens account and verify your email. To look around first, open Sign in — the demo account is already filled in.
  2. Open the dashboard. A project is created for you automatically.
  3. Copy the project API key from the dashboard sidebar.
  4. Install the Node SDK in your application.
  5. Call TraceLens.init() once at startup.
  6. Run the app and trigger an error.
  7. Refresh the dashboard — the incident should appear.
  8. Open it and click Ask AI to explain.

GitHub / Deployment Tracking

Optional. Add a GitHub webhook so TraceLens records pushes next to your incidents. AI can use those recent commits when it explains an error.

In the GitHub repo: Settings → Webhooks → Add webhook

  • Payload URL: https://tracelens-7hdm.onrender.com/api/webhooks/github/<YOUR_API_KEY>
  • Content type: application/json
  • Event: Just the push event

AI Incident Analysis

Open an incident and ask AI to explain it. TraceLens uses the error, stack trace, and recent deployments to produce:

  • Root cause — what likely broke, and which commit may have caused it.
  • Suggested fix — a concrete change to try.
  • Deployment context — recent pushes from the GitHub webhook, if you connected it.
