Quickstart

Get TraceLens up and running in a few minutes. Instrument your application, send your first event, and view it in the TraceLens dashboard.

1Create a project

Create a new project in the TraceLens dashboard to get your Project ID and Ingest Key.

2Install the SDK

Install the TraceLens SDK for your platform.

bash 
# Node.js
npm install @tracelens/node

3Initialize the SDK

Initialize the SDK with your Project ID and Ingest Key.

typescript 
1  import {{ '{' }} TraceLens {{ '}' }} from '@tracelens/node';
2
3  TraceLens.init({{ '{' }}
4    projectId: 'proj_1234567890abcdef',
5    ingestKey: 'ingest_1234567890abcdef',
6    environment: 'production',
7  {{ '}' }});

Keep your Ingest Key secure.

Do not expose it in client-side code or public repositories.

4Send your first event

Capture and send an event.

typescript 
1  TraceLens.capture('user.login', {{ '{' }}
2    userId: 'user_123',
3    method: 'password',
4    success: true,
5    latencyMs: 142,
6  {{ '}' }});

View the event in the TraceLens dashboard within a few seconds.

SDK initialization parameters

ParameterType RequiredDescription
projectIdstringYesYour TraceLens Project ID.
ingestKeystringYesYour TraceLens Ingest Key.
environmentstringNoThe environment name (e.g., production).
releasestringNoThe application release version.
sampleRatenumberNoEvent sample rate from 0 to 1 (default: 1).
debugbooleanNoEnable debug logging.
